### ASL FIFO Example ###

#### What
- Example that makes use of ASL FIFO component.

#### Why
- Example will show end-users a reference implementation.

#### How
- The user provides the size of FIFO and size of element to use through command line argument.
- The user inputs are validated before proceeding.
- The memory will be allocated (malloc) and FIFO will be created.
- The test covers push/pop from single element up to maximum elements possible.
- The test covers cases of empty and full FIFO.
- The test terminates successfully after all tests are completed (or terminates on first error).
